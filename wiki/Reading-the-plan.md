# Reading the plan

*What each option card and each run in it tells you.*

Each plan is shown as an **option card**. Option 1 is the **fastest**: the fewest runs, usually at higher keys. Later options use more runs at lower keys, ending with the **easiest**. Pick the one that suits your group.

### Every run in a card shows

- **The dungeon** and **the key level** to run.
- **The affixes** for that level this week.
- **The time limit** and **the time you need to beat**.
- **How much rating** the run adds.
- **Top parses:** the key levels the top Warcraft Logs parses of your spec come from in that dungeon. See [Top parses](Top-parses.md).
