# Questions and fixes

*Answers to the things people ask most.*

**`/pp` opens a different addon.**

Patron Planner also uses `/pp`, and only one addon can have it. Use `/pushplanner` instead; it always opens Push Planner.

**Looking someone up by name doesn't work.**

Name lookups use the Raider.IO addon's data. Install the Raider.IO addon, or pick the player as your target or party member, or type their runs in by hand.

**Someone's numbers look a few days old.**

The Raider.IO addon's data is updated when that addon updates, so it can lag a few days. Players in your group or that you target are read live from the game instead.

**Other players' keys don't show.**

Their keys show when they run Push Planner, or when they and you both run an addon with LibKeystone, such as BigWigs. The game itself doesn't share other players' keys.

**Does it need a website or a login?**

No. Everything is read inside the game. The rating maths comes from Mythic Planner and RatingCalculator, both MIT licensed, with thanks.
